Mini Paint

my_paint.html

A tiny raster-based paint program: pencil, line, rectangle, ellipse and eraser tools, each with adjustable color and stroke thickness, drawn pixel-by-pixel onto a manual framebuffer using ImageData and a Bresenham line algorithm — no high-level canvas draw calls for the strokes themselves.
